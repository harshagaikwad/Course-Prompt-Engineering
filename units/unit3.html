UNIT 03 | 06 HOURS

Advanced Prompting Techniques

Explore advanced reasoning, agentic prompting, multimodal prompting, and programming APIs.

Learning Objectives

  • Explain Chain-of-Thought Prompting.
  • Apply Self-Ask Prompting.
  • Understand ReAct prompting.
  • Design multimodal prompts.
  • Create prompt templates using APIs.

Course Topics

1. Chain-of-Thought Prompting

A prompting approach that encourages structured reasoning for complex tasks.

2. Self-Ask Prompting

The model decomposes a complex question into smaller subquestions.

3. ReAct Prompting

ReAct combines reasoning and action to support tool-based problem solving.

4. Multimodal Prompting

Multimodal prompting combines text with images and other input modalities.

5. Prompt Templates Using Python APIs

Prompt templates can be created using programming frameworks such as LangChain and SDKs such as the OpenAI SDK.
