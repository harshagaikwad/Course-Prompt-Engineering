UNIT 02 | 06 HOURS

Foundations of Prompt Design

Learn the fundamental types, patterns, evaluation methods, and debugging techniques used in Prompt Engineering.

Learning Objectives

  • Explain zero-shot, one-shot, and few-shot prompting.
  • Apply common prompt patterns.
  • Evaluate prompt quality.
  • Identify hallucination and safety problems.
  • Debug ineffective prompts.

Course Topics

1. Zero-Shot Prompting

Asking a model to perform a task without providing examples.

2. One-Shot Prompting

Providing one example to guide the expected response.

3. Few-Shot Prompting

Providing multiple examples to demonstrate a task pattern.

4. Prompt Patterns

Instructional, delimiting, role-based, and Socratic prompts.

5. Prompt Evaluation Metrics

Accuracy, relevance, hallucination, consistency, and safety.

6. Prompt Debugging

Prompt debugging involves identifying ambiguity, missing context, poor instructions, and inappropriate output constraints.
