COURSE CONTENT

Explore the Course Units

Follow the five-unit learning journey and test your understanding with interactive quizzes.

UNIT 01

Introduction to Prompt Engineering & LLMs

Evolution of NLP to LLMs, tokens, embeddings, context windows, GPT, Claude, PaLM, Mistral, prompting, and fine-tuning.

UNIT 02

Foundations of Prompt Design

Zero-shot, one-shot, few-shot prompting, prompt patterns, prompt evaluation, and prompt debugging techniques.

UNIT 03

Advanced Prompting Techniques

Chain-of-Thought, Self-Ask, ReAct prompting, multimodal prompting, prompt templates, Python APIs, LangChain, and OpenAI SDK.

UNIT 04

Prompt Engineering for Domain-Specific Tasks

Coding assistance, conversational agents, educational, legal, medical, data analysis, and low-resource language applications.

UNIT 05

Prompt Safety, Bias, and Ethics

Bias, toxicity, misinformation, adversarial prompting, safety, evaluation, function calling, tool use, and RAG.
